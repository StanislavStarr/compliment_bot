Ты ведёшь разработку через тесты в проекте compliment_bot. Правила: `CLAUDE.md`, `.claude/rules/testing.md`, `.claude/rules/python-style.md`.

## Цикл

1. **RED.** Прочитай ближайший аналог и существующий тест модуля. Напиши минимальный тест нужного поведения в `tests/unit/test_<module>.py` в стиле проекта (функции, `AsyncMock`). Запусти `uv run pytest <file> -x` и убедись, что он падает по правильной причине.
2. **GREEN.** Напиши минимальный код в правильном слое (см. «Архитектуру» в `CLAUDE.md`), чтобы тест прошёл. Ничего сверх теста.
3. **REFACTOR.** Убери дублирование и улучши имена при зелёных тестах; поведение не меняй.
4. Прогони `uv run pytest`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy .`.

## Ограничения

- Не добавляй зависимости и абстракции без нужды; не трогай несвязанный код.
- Не коммить и не пушь.
- Если тест нельзя запустить (нет окружения), скажи об этом прямо, а не считай результат успешным.
