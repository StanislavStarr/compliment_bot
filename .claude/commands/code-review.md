# /code-review

1. Определи изменения: `git status` и `git diff HEAD`. Если изменений нет, сообщи об этом и остановись.
2. Запусти агента **code-reviewer** на этих изменениях.
3. Если затронуты:
   - модели, репозитории или миграции, то дополнительно **database-reviewer**;
   - ввод пользователя, AI-запросы, конфиг, Docker или CI, то дополнительно **security-reviewer**.
4. Сведи результаты в один отчёт, отсортированный по серьёзности. Исправления не вноси без просьбы.

$ARGUMENTS — необязательный путь или область ревью.
