# /tdd

Запусти агента **tdd-guide** для задачи: $ARGUMENTS

Цикл: RED (падающий тест) → GREEN (минимальный код) → REFACTOR, затем `/verify`.
Если задача затрагивает несколько слоёв или миграции, сначала предложи короткий план (агент **architect**) и дождись согласия.
